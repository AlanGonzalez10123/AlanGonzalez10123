# Hi there! 👋
Hey! I'm Alan Gonzalez Osorio, a first-generation Mexican-American and William & Mary alum with a double major in Computer Science and Applied Mathematics. I'm currently a Software Development Engineer at Leidos, where I develop software for Air Traffic Management systems using Ada and Linux-based tooling.

Outside of work, I enjoy building full-stack web applications with Python, React, and Next.js while exploring AI and machine learning. I love creating software that solves real-world problems, learning new technologies, and collaborating on projects that make a meaningful impact.
